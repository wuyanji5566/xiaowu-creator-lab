我的工作方法

从问题到可检查的产出

先选择一个明确场景，做一个能展示、能检查的小成果，再决定是否继续投入。

1. 输入与事实锁定

整理目标、受众、使用场景、素材来源与授权、产品事实、预算和时间。把已知事实、创作设定与待验证项分开记录。

2. 拆解与方案

影像先确定叙事、镜头和资产覆盖；产品先拆目标、功能、页面、数据与接口；工作流先定义输入、处理、人工判断和输出。

3. 代表样品验证

优先验证最难或最关键的一段：人物一致性、产品动作、核心页面、真实工具调用或数据格式。保留失败与修改记录，避免一次批量制作后返工。

4. 制作与人工检查

  • 逐项检查事实、字幕、画面、声音及素材授权。
  • 检查原型的错误处理、数据保存、权限与可恢复性。
  • 高影响结论、外发与交易设置明确的人工确认节点。

5. 交付与复盘

按约定输出成片或原型、必要的可编辑文件、使用说明、已知限制和后续建议。将方案、生成素材、样片、正式交付与客户验收分别记录。

实际限制

AI 生成可能出现人物、文字与产品结构错误；演示视频无法证明后端功能或生产稳定性；自动化依赖接口、权限、数据质量与第三方服务。未做的测试、未确认的授权和客户验收应明确标注。

三条可复用的实践路径

企业 AI 培训

需求调研 → 岗位任务分析 → 工具与能力匹配 → 课程设计 → 演示与岗位共创 → 结果检查 → SOP 沉淀。

课程研发

目标人群 → 学习目标 → 课程架构 → 课件与逐字稿 → 实操任务 → 评价标准 → 教学反馈与迭代。

AIGC 影视制作

创意策划 → 故事与剧本 → 分镜 → 角色/场景/道具资产 → 代表镜头验证 → 视频生成 → 后期剪辑 → 一致性与成片质检 → 约定交付。

这些是工作方法说明。具体项目使用了哪些步骤、是否自动化、产出了什么，以对应作品档案和演示为准。
